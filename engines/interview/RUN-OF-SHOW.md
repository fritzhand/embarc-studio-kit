# Run of show: recording the founder interview in a studio

For the Embarc Collective Studio, follow the room's quick start for the equipment. This page covers what to shoot
so the editor in this kit has what it needs. It works for any studio or quiet room.

| Time | What happens |
|---|---|
| 0:00 | Room set. Two chairs angled toward each other, the founder's chair facing the camera at about 30 degrees |
| 0:05 | Mics on: one clip-on mic each, a hand's width below the chin. Headphones on. Check both levels with a few sentences |
| 0:08 | Frame the shot: 16:9, the founder in the middle third, eyes a third of the way down. Leave room above the head. This framing also crops cleanly to 9:16 |
| 0:10 | Start recording. Say the date and "take one" so the file is easy to identify |
| 0:11 | Ten seconds of silence for room tone (the editor uses it to clean the sound) |
| 0:12 | The seeded interview, `QUESTIONS.md`, in order. The host takes notes of answers worth a second take |
| 0:40 | Second takes: the one-sentence pitch, and any answer the host flagged |
| 0:45 | Stop recording. Check the file plays and has sound before you leave |

## Extra footage worth five minutes

- **Hands on the product:** 30 seconds of the founder using it, from over the shoulder. It covers jump cuts.
- **A screen recording** of the product doing its main job, recorded on your laptop (QuickTime on a Mac, the
  Xbox Game Bar on Windows). Turn off notifications first.
- **A wide shot** of the conversation, if the studio has a second camera.
- **Photographs:** the team, the product, the customer's setting, if you have permission. The editor gives every
  still a slow push-in.

| File | Goes in |

| Screen recordings | `projects/<name>/footage/` |
